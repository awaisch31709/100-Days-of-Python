Welcome to the Cafe & Wifi API

Find laptop-friendly cafes around London. Use the routes below.

Full API documentation (Postman)

Routes

MethodRouteWhat it does
GET/randomOne random cafe
GET/allAll cafes
GET/search?loc=PeckhamCafes at a location (404 if none)
POST/addAdd a cafe (form: name, map_url, img_url, loc, seats, toilet, wifi, sockets, calls, coffee_price)
PATCH/update-price/<id>?new_price=£3.80Update a cafe's coffee price
DELETE/report-closed/<id>?api-key=...Remove a closed cafe (needs the API key)
